## 2. 배경지식

### 2.1 Transformer

Attention mechanism을 중심으로 입력 데이터 사이의 관계를 학습하는 신경망 구조.

- 각 단어가 다른 모든 단어를 **동시에 직접** 쳐다본다.
- 100번째 단어가 1번째 단어를 참고하고 싶다면, 99단계를 거치지 않고 곧장 참고한다.
- 모든 단어가 모든 단어를 동시에 쳐다보므로 GPU의 병렬 처리도 자연스럽게 살아난다.

> 이 "동시에 쳐다본다"를 수학적으로 구현한 것이 **Self-Attention**이다.

### 2.2 Query, Key, Value

Attention에서는 입력으로부터 세 가지 벡터를 만든다.

- **Query (Q)**: 현재 내가 찾고 싶은 정보
- **Key (K)**: 각 정보가 가지고 있는 특징
- **Value (V)**: 실제로 전달할 정보

---

## 3. 핵심 수식 — Self-Attention

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

### 1) $QK^T$ — Query와 Key의 닮은 정도

Q와 K의 전치를 내적한다. 두 벡터가 비슷한 방향을 가리키면 큰 값, 다른 방향이면 작은 값이 나온다.

**예시:** "나는 오늘 로봇을 공부했다."

$$
QK^T = \begin{bmatrix} 2 & 1 & 5 & 0 \end{bmatrix}
$$

| 정보 | 관련성 점수 |
|---|---|
| 나는 | 2 |
| 오늘 | 1 |
| 로봇 | 5 |
| 공부했다 | 0 |

→ 현재 Query는 '로봇' 정보와 가장 관련성이 높음

### 2) $\sqrt{d_k}$ — 점수 크기 조정 (Scaling)

$$
\frac{QK^T}{\sqrt{d_k}}
$$

- $d_k$: Key의 차원(dimension)
- Q와 K의 차원이 커지면 내적 결과의 값도 커질 수 있음
- 값이 너무 커지면 뒤의 Softmax가 한쪽 값에 지나치게 집중될 수 있음
- 따라서 $\sqrt{d_k}$로 나누어 값을 적절한 범위로 조정함

**예시:** $d_k = 64$라면

$$
\sqrt{d_k} = \sqrt{64} = 8
$$

$$
QK^T = [20,\ 50,\ 100]
$$

$$
\frac{QK^T}{\sqrt{d_k}} = \frac{[20,\ 50,\ 100]}{8} = [2.5,\ 6.25,\ 12.5]
$$

→ Scaling을 통해 Softmax에 들어가는 값의 크기를 안정적으로 조정한다.

### 3) Softmax — 비율로 변환

점수들을 모두 양수로 만들고 합이 1이 되도록 변환한다.

$$
[2,\ 1,\ 5,\ 0] \rightarrow [0.047,\ 0.017,\ 0.936,\ 0.002]
$$

### 4) V — 비율로 Value 합치기

위에서 만든 비율로 다른 토큰들의 Value를 가중 평균한다. 결과는 "관련 있는 토큰의 내용을 더 많이 섞은 새로운 표현"이다.

Softmax의 결과가 $[0.047,\ 0.017,\ 0.936,\ 0.002]$이고, 각 값에 대응하는 Value가

$$
V = \begin{bmatrix} v_1 \\ v_2 \\ v_3 \\ v_4 \end{bmatrix}
$$

라면, 결과는 다음과 같이 계산된다.

$$
0.047v_1 + 0.017v_2 + 0.936v_3 + 0.002v_4
$$

## 5. Multi-head attention - 한 번이 아니라 여러번
위 수식을 한 번만 적용하면 한 가지 관점으로만 정보를 모은다. 그런데 실제로는 한 단어가 여러 관점에서 다른 단어와 관계를 맺는다.
그래서 Q, K, V를 여러 벌 만들어 각자 따로 attention을 계산하고, 결과를 이어 붙인다. 이것이 Multi-head attention이다.

예를 들어:
- Head 1 → 문법적 관계
- Head 2 → 의미적 관계
- Head 3 → 먼 거리의 토큰 관계

각 Head에서 계산한 결과를 이어 붙인 후(Concatenate), Linear Layer를 통해 최종 출력으로 변환한다.

정리 : 각각의 attention이 서로 다른 종류의 관계를 학습

## 6. Feed-Forward Network - 한 블록은 attention 하나로 끝나지 않음
트랜스포머 한 블록(Layer)에는 두 가지가 짝을 이뤄 들어간다.

```
[입력 토큰] → Multi-head Attention → Feed-Forward Network → [출력 토큰]
```

Feed-Forward Network(FFN) 는 각 토큰을 따로따로 작은 신경망에 통과시키는 부분이다. 

일반적으로 중간 차원을 크게 확장했다가(약 4배) 다시 원래 차원으로 줄인다.
-> 중간 차원을 크게 만들어서 더 복잡한 특징을 표현하고 변형할 수 있게 하기 위해서

### 핵심
attention : 다른 토큰과 정보를 주고 받음
FFN : 각 토큰의 정보를 가공함

---

## 7. Residual connection, Layer normalization - 깊게 쌓기
트랜스포머는 이런 블록을 보통 여러 층 깊게 쌓는다. 그런데 신경망을 그렇게 깊게 쌓으면 보통 위쪽 층까지 학습 신호가 잘 닿지 못해 학습이 멈춘다. 이를 해결하기 위해 **Residual Connection(잔차 연결)**, **Layer Normalization**을 사용한다.

### 1) Residual connection
입력을 그대로 전달하면서 Block의 결과(변한 만큼)를 더한다.

```
          ┌──────────────┐
          │              ↓
입력 ─────┼───────────── (+) → 출력
          │              ↑
          ↓              │
        Block ───────────┘
```

### 2) Layer normalization
각 토큰 벡터의 값을 일정한 분포(평균 0, 표준편차 1 근처)로 맞춰주는 작업. 
층마다 값이 들쭉날쭉해지지 않게 다듬어 학습을 안정시킨다.

## 8. Positional encoding
트랜스포머의 Attention은 모든 토큰을 동시에 병렬로 처리하지만, 단어들의 순서를 알 수 없다. 
그래서 입력 단계에서 토큰 임베딩에 순서 정보를 살짝 더해준다. **각 위치마다 고유한 패턴을 가진 작은 신호를 더하는 식**

## 9. VLA가 여기서 받는 것
VLA에서 가장 흔한 구조는 "이미지 토큰 + 언어 토큰 + 행동 토큰을 한 시퀀스로 이어 붙여  
트랜스포머에 넣는 것"이다. 이게 가능한 이유가 self-attention이다. 어떤 종류의 토큰이든  
자유롭게 서로를 참고할 수 있으니, 이미지 토큰이 언어 토큰을 참고하고 그 결과로 행동 토큰을  
출력하는 흐름이 자연스럽게 풀린다.

> 트랜스포머는 "어떤 정보든 토큰으로 펼쳐 한 모델로 처리한다"는 그릇이다. VLA는 그 그릇  
> 위에 비전, 언어, 행동을 올려놓은 구조이다.

## 헷갈리는 것
### 1) 트랜스포머는 병렬로 토큰을 처리하는데 왜 Transformer x N이 나왔나
-> Transformer는 토큰끼리는 병렬로 처리하지만, Transformer Block은 여러 층을 순차적으로 통과한다. 즉, 각 Block 안에서는 모든 토큰을 병렬 처리하지만, 블록의 순서는 유지됨.
