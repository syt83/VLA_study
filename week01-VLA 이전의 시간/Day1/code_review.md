# Day 01 — Transformer code review

## self-attention 구현

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

self-attention의 핵심 수식을 파이썬으로 구현해보았다.

입력 토큰을 x, Query를 Q, Key를 K, Value를 V로 선언 후 총 4단계로 분류해서 구현해보았다.
여기서 W_q, W_k, W_v는 각각 입력 x를 각각 벡터(Q, K, V)로 바꾸기 위한 가중치 행렬이다.

---

### 1) $QK^T$ — Query와 Key의 닮은 정도
```
scores = Q @ K.transpose(-2, -1)
```

Q와 K의 내적을 이용하여 각 Query가 각 Key와 얼마나 관련되어 있는지 점수를 계산한다. 이때 행렬 곱셈을 수행하기위해 K의 마지막 2차원을 전치시다.

### 2) $\sqrt{d_k}$ - 점수 크기 조정(Scaling)
```
s_size = scores / sqrt(d_k)
```
$\sqrt{d_k}$ 를 나누어준다. 벡터의 길이가 길수록 dot product의 값이 매우 커진다. 이는 softmax가 한쪽으로 몰려 학습이 잘 되지 않으므로, 적당한 크기로 맞춰준다.

### 3) softmax() - 비율로 변환
```
weights = F.softmax(s_size, dim = -1)
```
관련성 점수를 **각 토큰을 얼마나 참고할지 나타내는 비율(Attention Weight)**로 변환한다. 이 때 해당 행의 값들을 모두 더하면 1이된다.

### 4) V — 비율로 Value 합치기
```
out = weights @ V
```
위에서 만든 비율로 다른 토큰들의 Value를 가중 평균한다. 각 토큰의 Weight가 높을수록 해당 토큰의 Value 정보가 최종 출력에 더 많이 반영된다.

ex)
```
V₁ = [10,  2,  8]            토큰1 = [0.1, 0.2, 0.6, 0.1]
V₂ = [20,  4,  6]
V₃ = [30, 10,  2]
V₄ = [40,  8,  4]

새로운 V
=
0.1 × V₁             
+ 0.2 × V₂
+ 0.6 × V₃
+ 0.1 × V₄

첫 번째 차원:
0.1×10 + 0.2×20 + 0.6×30 + 0.1×40
= 27

두 번째 차원:
0.1×2 + 0.2×4 + 0.6×10 + 0.1×8
= 7.4

세 번째 차원:
0.1×8 + 0.2×6 + 0.6×2 + 0.1×4
= 3.8


새로운 표현
= [27, 7.4, 3.8]

```

### 구조
결과를 보고 구조를 파악하면
```
out
│
├── batch 1개
│
└── 4개의 토큰
     │
     ├── 토큰 1 → 8개의 숫자
     ├── 토큰 2 → 8개의 숫자
     ├── 토큰 3 → 8개의 숫자
     └── 토큰 4 → 8개의 숫자
```
이 됨을 알 수 있다.

### 새로 알게된 것
코드에서 x.shape(1, 4, 8)은 각각 batch, 토큰의 개수, 각 토큰을 표현하는 차원의 수를 말한다.
이 때 토큰을 임베딩 벡터로 변환하면 숫자들의 벡터가 된다.

```
"나는"          ← 토큰
  ↓
임베딩
  ↓
[0.21, -0.73, 1.42, ..., 0.18]

그리고 이 벡터가 W_와 곱해져서

임베딩 X
   │
   │ × W_q
   ↓
Query Q

가 된다.
```

## 예시
한글 2글자를 1토큰이라고 가정

나는 차를 좋아한다

이 문장을 토큰이 4개라고 단순화하면 아래와 같다.
```
토큰 1 → "나는"
토큰 2 → "차를"
토큰 3 → "좋아"
토큰 4 → "한다"
```
그리고 각각을 8차원 임베딩으로 표현할 수 있다
```
"나는" → [0.2, -0.4, 0.8, ..., 0.1]  ← 8개
"차를" → [0.5,  0.2, 0.1, ..., 0.7]  ← 8개
"좋아" → [0.1,  0.9, 0.3, ..., 0.2]  ← 8개
"한다" → [0.7, -0.1, 0.4, ..., 0.5]  ← 8개
```

이번 코드는 랜덤한 숫자 4개를 만들었으므로 어디까지나 트랜스포머의 구조를 파악하기 위한 예시이다.

### 모르는 코드
@ : 행렬 곱셈
torch : pytorch 라이브러리 => 숫자 계산, 행렬 계산, 딥러닝 수행
manual_seed(0) : 랜덤 숫자를 똑같이 나오도록 설정
randn(1, 4, 8) : 배치 1개, 토큰 4개, 각 토큰 랜덤한 숫자를 만들어주는 함수
tensor : 숫자들을 원하는 차원으로 묶어놓은 것
