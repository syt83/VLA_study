## 2. 배경지식

### 2.1 VIT

CNN : 이미지에 작은 윈도우를 슬라이딩하며 지역적 특징(가장자리, 무늬)를 뽑는 구조, 2020년까지 비전 분야의 표준  

문제점
1) 언어는 트랜스포머로 통일되었지만, 비전은 여전히 CNN이라,  
   한 모델로 합치고 싶어도 구조가 달라 매끄럽게 호환되지 않음

2) CNN은 작은 윈도우에서만 정보를 보기 때문에 이미지 전체 맥락을 보려면
   층을 여러개 쌓아야만 했음

**=> 이미지를 패치로 잘라서 Transformer의 입력 토큰처럼 처리**

#### 처리 방식
ex) 

1) 이미지의 크기가 224x224이고, 패치의 크기가 16x16 일때,  
   가로로 14개, 세로로 14개 총 196개의 패치가 만들어진다.

2) 패치는 아직 크기가 16x16인 이미지이다. 패치가 RGB이미지라면 16x16x3개의 픽셀 값을 가진다.  
   이를 펼친 후, Linear Layer를 통과시켜서 트랜스포머가 사용할 임베딩 벡터(토큰)로 변환시킨다. 
   이를 patch embedding이라고 한다.

   ```
   16 × 16 × 3
      ↓
    Flatten
      ↓
   768개의 숫자
      ↓
   Linear Layer
      ↓
   768차원 벡터
   ```
3) 이후 위치를 정렬시키기 위해 positional embedding을 더해준다.

4) 패치들 앞에 CLS토큰을 하나 추가한다. 여기서 CLS토큰은 이미지 전체 정보를 모으는 역할을 한다.

#### 전체 구조

 ViT (Vision Transformer) 전체 구조

```
                       입력 이미지
                           │
                           ▼
                  ┌─────────────────┐
                  │   Patch 분할    │
                  └────────┬────────┘
                           │
                           ▼
                  ┌─────────────────┐
                  │ Patch Embedding │
                  └────────┬────────┘
                           │
                           ▼
              [P1] [P2] [P3] ... [PN]
                           │
                    + Position
                           │
                           ▼
              ┌────────────────────────┐
              │   Vision Transformer   │
              │                        │
              │  Multi-Head Attention  │
              │           ↓            │
              │  Residual + LayerNorm  │
              │           ↓            │
              │          FFN           │
              │           ↓            │
              │  Residual + LayerNorm  │
              └────────────┬───────────┘
                           │
                       Encoder × N
                           │
                           ▼
            [Visual Token 1] ... [Visual Token N]
                           │
                           ▼
                    Vision Encoder
                       출력
                           │
                           ▼
              VLA의 다음 모듈로 전달
```

## 3. VLA가 여기서 받은 것
ViT 이후 거의 모든 비전 모델이 패치 기반 트랜스포머로 통일되었다. RT-1, RT-2,  
OpenVLA, π₀의 비전 인코더는 전부 ViT계열의 후손이다.
더 중요한 것은 형식의 통일이다. 이미지가 토큰 시퀀스로 표현되면서, "언어 토큰 +  
이미지 토큰 + 행동 토큰"을 한 모델 안에서 처리할 수 있게 되었다.

> ViT는 "이미지도 토큰"이라는 발상으로 비전을 트랜스포머로 올렸다.
